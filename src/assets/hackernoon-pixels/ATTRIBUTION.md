# HackerNoon Pixel Icon Library

Original SVG assets by [HackerNoon Pixel Icon Library](https://pixeliconlibrary.com/),
licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Source: [upstream regular SVGs at 5fe05c9](https://github.com/hackernoon/pixel-icon-library/tree/5fe05c9c81a3eb43448e820b4521307102c248e7/icons/SVG/regular).
The SVGs are stored unchanged. The site scales them and uses their alpha
as a CSS mask so they inherit the current theme's text color.
